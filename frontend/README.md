# SafePath - Frontend

The frontend client for **SafePath**, built with React. This application provides an interactive map interface to help users navigate and plan safe routes.

---

## 🚀 Features

* **Interactive Map Integration:** Real-time location visualization and route rendering.
* **Responsive UI:** Optimized for both desktop and mobile web viewports.
* **Safety Routing:** Visualizes safe paths and points of interest dynamically.

---

## 🛠️ Tech Stack

* **Framework:** React.js
* **Build Tool:** Create React App
* **State & Routing:** React Router / Context API
* **Maps & Geolocation:** Leaflet / Mapbox / Google Maps API *(adjust based on your setup)*
